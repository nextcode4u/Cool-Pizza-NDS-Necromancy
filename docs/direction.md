# Project direction

Cool Pizza: Necromancy develops new content and improvements from the
Cool Pizza DS reconstruction. The starting game uses the original version 1.4
assets, wave progression, combat and ghost powers.

## Scope

| Area | Development opportunities |
| --- | --- |
| Performance | Smoother presentation and improved emulator/device compatibility |
| Controls | Configurable buttons, touch controls and accessibility options |
| Gameplay | New enemies, waves, powers and difficulty options |
| Progression | Additional modes, challenges and replay features |
| Presentation | Expanded effects, animation and interface improvements |
| Saving | More game settings and progression data |

These are directions for future work; the initial project establishes the
buildable baseline. Changes should describe their gameplay effect and include
appropriate testing.

## Original reconstruction

The [Cool Pizza DS repository](https://github.com/nextcode4u/Cool-Pizza-NDS-)
focuses on reproducing the original game. Necromancy is maintained separately
so experimental features can develop without changing that project's scope.
